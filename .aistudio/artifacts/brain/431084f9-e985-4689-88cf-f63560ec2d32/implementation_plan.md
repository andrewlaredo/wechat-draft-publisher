### 第一阶段落地清单

1. **微信微版式视觉物料库（Micro-layout Component Library）**：
   - 物料库已全面扩展至 15 款高频微信排版组件，新增独立「风格分割线」等核心分类：
     - **居中超大双引号经典金句框**（`center-giant-quote`，优雅衬线大号引号与居中格言）。
     - **渐变数字圆标三步核心卡**（`numbered-steps-pills`，01/02/03 醒目渐变徽标）。
     - **文首引导关注与星标置顶条**（`header-follow-banner`，预计阅读时长与公众号名片）。
     - **核心速览与关键结论清单卡**（`key-takeaways-card`，绿色对勾清单）。
     - **文末作者签名与二维码名片卡**（`author-signature-footer`，作者头像、简介与扫码关注卡槽）。
     - **风格分割线系列**：剪刀裁切虚线（`divider-scissor` ✂️）、极简微光双向渐隐线（`divider-gradient`）、雅致几何菱形三点线（`divider-diamonds` ◆ · ◆ · ◆）。
     - **清新技巧与成功提示框**（`tip-success-card`，青绿底色柔光微框）。
   - 弹窗增加分类即时联动预览（`displayItem` 动态兜底），一键插入当前编辑器光标位置并支持复制代码片段。

2. **盘古中英文排版规范化（Pangu.js 深度集成）**：
   - 接入官方现代 `pangu` 核心引擎，配合中文文案排版指北（Chinese Copywriting Guidelines）：
     - 智能在 CJK 汉字与英文单词、阿拉伯数字之间插入标准盘古之白空格。
     - 全流程严密保护 Front-Matter、多行代码块、行内代码、LaTeX 数学公式、Markdown 图片与超链接、HTML 标签/组件注释以及原生 URL，确保语法结构 100% 零破坏。
     - 中文语境下的英文半角标点智能纠正（逗号 `,` 转 `，`、分号 `;` 转 `；`、冒号 `:` 转 `：`、问号 `?` 转 `？`、叹号 `!` 转 `！`）。
     - 标点符号重复过度消除（`！！！` 转 `！`、`？？？` 转 `？`、`。。。` 转 `。`）。
     - 4 行以上无意义空白折叠为适度呼吸感空行。
   - 工具栏与体检医生提供即时操作反馈与精确变更统计（如：优化了 X 处盘古空格、Y 处标点规范、Z 处冗余空行）。

3. **微信外链智能转文末优雅脚注（Link-to-Footnote Generator）**：
   - **双轨运作机制**：
     - **实时渲染/复制流**：工具栏增加 `[外链转脚注: 开/关]` 独立开关（支持 LocalStorage 记忆）。开启后，在实时双栏预览以及“一键复制微信排版”时，自动将正文所有非微信官方外链替换为上标角标 `^[1]`，并在文末生成 100% 微信富文本内联样式的「📚 参考资料与延伸阅读」卡片，无需改动用户本地原始 Markdown 文本。
     - **源码一键转换流**：编辑器快捷工具栏提供 `[外链转脚注]` 按钮，支持用户一键将草稿中的外链重构写入 Markdown 文本本身。
     - 自动识别并保留微信内部链接（`mp.weixin.qq.com`）不予截断。

4. **自动化测试与工程验证**：
   - 新增 `tests/phase1.test.ts` 包含 11 项深度单元测试。
   - 24 项全套单元测试 100% 全部通过。
   - `tsc --noEmit` 零语法类型报错，`compile_applet` 生产打包成功。
