# 微信排版编辑器后续开发与 Mermaid 深度重构规划

排查定位了 Mermaid 矢量图表未正常呈现的底层原因，并制定了后续迭代规划（包含图表修复、快捷插入模板、多平台排版导出、素材库扩展与智能辅助），待用户确认后即刻推进落地。

***

### 关键排查发现与核心决策

> [!IMPORTANT]
> **Mermaid 功能“不见了”的技术根因排查报告**：
> 1. **代码渲染层被错误包裹**：在 `createMarkdownRenderer` 中，原实现在 markdown-it 的 `options.highlight` 钩子中返回 SVG，但 markdown-it 规范规定：若返回的 HTML 不以 `<pre` 开头，其外部会被强制套上一层 `<pre><code class="language-mermaid">`。这导致原本精美的纯矢量 SVG 被代码高亮容器的深色等宽格式包裹截断，视觉上形同失效。
> 2. **缺少交互插入入口**：编辑工具栏仅有粗体、斜体、代码、表格、图库等基础项，完全缺少「📊 插入图表 / Mermaid」按钮，用户只能靠手写三反引号代码块。
> 3. **默认示例文档未展示**：`samples.ts` 中的默认指南文章缺少 Mermaid 真实示例，导致开箱预览时无法感知该功能。
> 4. **决策项（待确认）**：
>    - **方案 A（推荐）**：使用 `md.renderer.rules.fence` 直接拦截 `mermaid`，彻底规避 `<pre>` 包裹，输出 100% 微信安全内联样式的矢量 SVG，并在工具栏新增可视化「插入图表」菜单（含流程图、时序图、架构图等开箱即用模板）。
>    - **后续功能演进优先级**：建议先完成【阶段一：Mermaid 修复与可视化图表模板库】，再推进【阶段二：多平台适配与导出】和【阶段三：高级微信素材库】。

***

## 1. 总体目标与核心定位

- **产品定位**：打造无代码、免排版痛苦的一站式微信公众号及多平台自媒体技术/深度文章排版神器，原生支持 Markdown、LaTeX 数学公式与 Mermaid 矢量图表全端免图床直出。
- **目标用户**：技术博主、知识自媒体、产品经理、高校科研工作者及运营团队。
- **核心价值**：
  - 复制即所见：直接生成 100% 微信兼容的内联 SVG / HTML，无需生成外部图片，无需配置图床，彻底解决公众号外链图防盗链失效问题。
  - 零门槛图表化：告别手写 Mermaid 语法记忆负担，提供所见即所得图表模板。

### 阶段一：Mermaid 矢量图表全面复活与交互模板（优先实施）
1. **核心渲染引擎底层修复**：
   - 将 Mermaid 处理从 `highlight` 钩子移至 `md.renderer.rules.fence`，规避 `<pre><code>` 的自动包裹。
   - 增强横向流程图 (LR)、纵向流程图 (TD) 与时序图 (sequenceDiagram) 的自适应视口比例（viewBox 动态缩放），在手机微信端双指可放大、横向平滑滚动。
2. **工具栏「📊 插入图表」入口与模板抽屉**：
   - 工具栏显式新增「图表 (Mermaid)」按钮，点击弹出快捷模板选择：
     - **业务流程图**（Start -> 处理 -> 审核 -> Finish）
     - **系统架构图**（客户端 -> API 网关 -> 微服务 -> 数据库）
     - **交互时序图**（用户 -> 前端 -> 微信登录鉴权 -> 成功回调）
   - 插入时光标智能聚焦，代码块内带注释引导用户快速修改文字。
3. **默认示例文章（samples.ts）升级**：
   - 在“公众号排版完整演示”中置入一组生动清晰的业务流程图与时序图，让用户一键切换时立即可见。

### 阶段二：多平台适配与一键导出管道
1. **多格式分发转换器**：
   - **微信富文本复制**（一键写入系统剪贴板，保留内联样式、公式与 SVG 矢量图）。
   - **知乎专栏模式**：将外部图片与链接转化为知乎防吞排版规范。
   - **离线 HTML + SVG 完整包下载**：无依赖单个 HTML 文件，便于自建博客或离线存档。
2. **手机真机扫码审稿深度调优**：
   - 保持前序已完成的局域网与域名统一隧道预览，增加“缩放比率切换（100% / 110% / 125%）”，模拟不同长辈或系统字号下的排版断行。

### 阶段三：微信高级排版组件与视觉素材库
1. **微信专属交互样式**：
   - 划重点荧光高亮标记（手绘风格下划线 / 黄色荧光笔底色）。
   - 知识点折叠卡片（点击展开查看答案或详情）。
   - 金句引言卡片与作者简介浮层。
2. **排版质量即时雷达**：
   - 结合前序的微信 SEO 检测器，增加“移动端阅读舒适度指数”（字号行距健康度、段落过长预警、图文密度评估）。
